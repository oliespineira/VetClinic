VETCLINIC - RUNNING INSTRUCTIONS
================================

1. REQUIREMENTS
---------------
- Java 21 (JDK). Check with:  java -version
  [TODO team: confirm once pom.xml is set to Java 21 and the JAR is tested on Java 21]
- Nothing else. The database (H2) is built in and runs in memory.

2. START THE APPLICATION
------------------------
Option A - from the executable JAR (recommended):
    java -jar TeamName_VetClinic.jar

Option B - from the source code (in the project folder):
    macOS / Linux:  ./mvnw spring-boot:run
    Windows:        mvnw.cmd spring-boot:run

Wait until the console shows:  Started VetClinicApplication

To run the unit tests:
    ./mvnw test        (Windows: mvnw.cmd test)

3. WHERE TO OPEN IT
-------------------
- The application is a REST API on port 8080:  http://localhost:8080
- All endpoints are under /api, for example:   http://localhost:8080/api/medical-records/1
- If port 8080 is busy, start it on another port:
    java -jar TeamName_VetClinic.jar --server.port=8081

4. LOGINS (one per role)
------------------------
Every request needs a login (HTTP Basic). In Postman: Authorization tab -> Basic Auth.
With curl:  curl -u EMAIL:PASSWORD http://localhost:8080/api/...

    Role             Email                         Password
    ---------------  ----------------------------  ------------
    Receptionist     reception@pawcare.example     reception123
    General vet      vet@pawcare.example           vet123

6. DATABASE
-----------
No setup needed. The JAR uses an in-memory H2 database, created at startup.
Note: data is reset every time the application restarts.
